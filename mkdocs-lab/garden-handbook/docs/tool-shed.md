# The Tool Shed

The shed holds the garden's shared
tools. The combination is given to
every plot holder at the spring
meeting; it changes each season.

## What's in there

| Tool            | Count | Notes                  |
| --------------- | ----: | ---------------------- |
| Wheelbarrow     |     2 | Tyres pumped in March  |
| Spade           |     4 | One is short-handled   |
| Fork            |     3 |                        |
| Hoe             |     4 | Dutch and draw hoes    |
| Watering can    |     6 | Two leak; use the others |
| Secateurs       |     3 | In the tin on the shelf |
| Petrol mower    |     1 | Trained users only     |

## Borrowing rules

1. Take what you need, when you need
   it — there is no booking sheet for
   hand tools.
2. Clean soil off before you put a
   tool back. The bucket and brush
   are by the door for exactly this.
3. Broken something? Leave it on the
   workbench with a note, and tell a
   committee member. Tools get mended
   at the winter meeting.

??? note "The mower is the exception"
    The mower needs fuel, a safety
    check and an adult who has been
    shown how. Ask before your first
    use; after that, sign the sheet
    on the shed door so the garden
    knows the paths have been done.
